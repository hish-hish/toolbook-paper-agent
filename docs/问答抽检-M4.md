### B3 论文的协方差参数化接收机属于用先验的统计估计；书里 LMMSE 信道估计的原理是什么？

> 说明：B3 初测即 PASS（9 句，命中 7.4 公式）。修复 B4 指代问题后重启服务复测，B3 答案更完整，下面记录**复测最终版**。

**答案**（重试 1 次）：
- [机械✓] 对y = Ah + n，零均值信道协方差Rh、噪声协方差C已知时，线性最小均方误差估计为 bh = RhAH(ARhAH + C)−1y. [3]
- [LLM✓] LMMSE估计器在所有线性估计器中最优；若信道与噪声联合高斯，它也等于真正的MMSE估计。 [3]
- [机械✓] 设零均值向量h ∈Cp、观测y ∈Cm，在线性类中令bh = By。误差与所有线性观测正交是最小均方误差的必要充分条件： E[(h −By)yH] = 0. [4]
- [LLM✓] 由此正交原理可推导出LMMSE估计器的系数矩阵B = RhyR−1y，其中Rhy = E[hyH]，Ry = E[yyH]。 [4]
- [机械✓] 当y = Ah + n且信道与噪声不相关， Ry = ARhAH + C. Rhy = RhAH, [4]
- [LLM✓] 将上述关系代入B = RhyR−1y，即可得到LMMSE估计器的具体公式。 [4]
- [机械✓] LMMSE：把可靠先验转成正则化 [1]
- [LLM✓] LMMSE估计利用了信道协方差Rh等先验统计信息，将先验知识转化为估计中的正则化项。 [1]
- [机械✓] 若先验均值非零，应先减均值再加回。 [3]
- [机械✓] 协方差失配时优势可能消失，所以仿真应同时画理想先验与失配先验。 [3]
- [机械✓] 若真实分布偏离先验，估计可能发生系统性偏差。 [0]
